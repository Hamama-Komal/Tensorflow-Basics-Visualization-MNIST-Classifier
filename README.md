# Tensorflow Basics, Visualization and MNIST Classifier Project

A complete hands-on learning series built with TensorFlow. This repository contains three Jupyter notebooks that guide you from basic TensorFlow concepts to a fully functional MNIST handwritten digit classification project.

---

## 📌 Contents

### **1. TensorFlow Basic Model**
File: `1_Tensorflow_Basic_Model.ipynb`  
This notebook introduces essential TensorFlow operations including:
- Creating tensors  
- Basic tensor manipulations  
- Building a simple neural network model  
- Forward pass and training basics  

---

### **2. TensorFlow Visualization**
File: `2_Tensorflow_Visualizing.ipynb`  
Focused on understanding model behavior through visualization:
- Visualizing tensors  
- Plotting model performance  
- Using Matplotlib & TensorFlow utilities for insights  

---

### **3. MNIST Digit Classifier Project**
File: `3_Tensorflow_MNIST_Digit_Classifier_Project.ipynb`  
A complete practical project:
- Loading the MNIST dataset  
- Preprocessing images  
- Building & training a CNN/ANN classifier  
- Evaluating accuracy and visualizing predictions  

---

## 🎯 Learning Goals
- Understand TensorFlow fundamentals  
- Learn how to visualize data and model performance  
- Build a real-world deep learning project from scratch
